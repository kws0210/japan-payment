### 돈키호테 점포 팝업·수수료 조사 (2026-10-22)

하단 버튼은 ‘모름’·‘확인’이며 선택 전 ‘확인’은 비활성화하고 선택 지점명을 표시한다.
검색은 임시 선택을 유지하며 ‘모름’은 임시 선택을 버리고 미확인 지점으로 적용한다.
그 외·미확인은 전용 두 행사만 제외하며 KB 공통 10%·보유 매장 쿠폰은 유지한다.
공항은 장소·금액만, 그 외는 유니온페이 결제 가능 여부만 추가 확인한다.

### 수수료 계산·준비 목록 간소화 완료 (2026-10-22)

KB 노리 체크(UnionPay)는 예시 상품 가정을 유지하며, 트래블카드는 사용자 정정에 따라 트래블월렛 엔화 잔액 결제 기준이다.
상품명 답변 대기 때문에 구현을 미루던 상태는 해소됐으며 가정임을 화면에 표시한다.
노리 이용료는 상품 페이지 0.25%와 일반 안내의 0.6~0.8%+0.25% 불일치 때문에 즉시 할인 후 결제액의 0.25~1.05% 예상 범위로 계산한다.
이 범위는 현재 확정 요율이나 환전 비용 전체의 상한이 아니다.
트래블월렛 공식 엔화 환전·해외 결제 수수료 0%를 반영하며 실제 충전 환율과 별도 잔액 환불 거래를 구분한다.
카카오페이는 제휴사 수수료가 앱 환율에 포함되며 공개 실결제 환율 API·고정 요율이 미확인이라 비용을 null로 유지한다.
카카오 후보가 있어도 확인된 KB 이용료를 차감하며 카카오 앱 환율 비용은 null인 잠정 비교다.
카카오 후보가 없으면 같은 환율 가정에서 KB 예상 이용료 상한을 차감해 비교한다.
수수료·실결제 환율 입력란은 제거하고 확인된 이용료를 자동 반영한다.
KB는 할인 후 결제액의 1.05%를 예상 할인액에서 한 번 차감하며 실제 환율 차이는 미반영이다.
브라우저에는 로그인만 유지하며 수수료 입력 상태나 견적을 저장하지 않는다.
요청 환율은 operations 결과에 함께 남지만 다음 로그인에서 설정으로 복원하지 않는다.
자동 참고 환율은 USD/JPY·KRW를 함께 조회하며 실제 청구/충전 환율로 간주하지 않는다.

사용자는 준비 페이지가 장황하다며 준비할 일만 목록으로 두고 펼치기를 활용하라고 요청했다.

로그인 없이 준비 가이드·근거 페이지를 열며 새 저장 상태를 추가하지 않는다.

## 전화번호 로그인·Firebase

사용자는 전화번호만 입력하는 방식을 선택했으며 번호를 아는 사람도 기록을 조회·변경할 수 있음을 확인했다.
문자 인증과 비밀번호는 사용하지 않는다.
국내 번호와 +82 표기를 정규화한 SHA-256을 계정 ID로 사용하고 Firestore에 원문 전화번호를 저장하지 않는다.
번호 해시는 소유자 인증이나 번호 추측 방지용 비밀번호가 아니다.
첫 접속은 번호 입력 화면, 로그인 정보가 남아 있으면 서버 조회 후 계산 화면, 상단 로그아웃은 다시 번호 입력 화면으로 돌아간다.

전용 프로젝트는 kws0210-japan-payment이며 기본 Firestore는 asia-northeast3(서울)의 무료 등급이다.
웹앱 ID는 1:438046477426:web:f1d56b62cdead3dfcd46eb이다.
사용자가 Firebase Authentication의 시작하기를 눌러 기본 서비스를 초기화했다.
익명 로그인 활성화와 kws0210.github.io 인증 허용 도메인 등록을 API로 확인했다.
Firebase 웹 SDK 12.19.0의 Authentication과 Firestore Lite를 사용하며 별도 서버·Cloudflare는 운영하지 않는다.
브라우저 로그인 키는 japan-payment:session:v1이며 Firestore Lite는 카운트를 디스크에 캐시하지 않는다.
서버의 paymentAccounts/{번호 해시}와 하위 operations/{요청 ID}를 트랜잭션으로 함께 저장해 동시 계산과 재시도 중복을 방지한다.
동시 쓰기가 규칙 평가에서 permission-denied로 충돌하면 서버 버전이 실제로 증가한 경우에만 최신 기록으로 다시 계산한다.
로그아웃 뒤 도착한 이전 요청의 응답은 새 계정 화면에 반영하지 않는다.
저장 규칙은 인증 없는 접근·목록 조회·계정 삭제·한도 초과 증가·요청 기록 덮어쓰기를 금지한다.
번호를 알고 접속하는 방식이므로 익명 인증한 이용자는 알고 있는 계정 문서에 접근할 수 있다.

기존 로컬 카운트는 사용자 확인 후 사용 이력이 없는 번호로만 가져오며 가져오기 또는 폐기를 결정하기 전까지 보존한다.
가져오기 후 이전 localStorage 카운트 키를 제거한다.
설정·규칙·회귀 검증은 공개 저장소의 _japan-payment-firebase/에 있으며 Jekyll 기본 게시에서는 제외된다.
해당 디렉터리의 node_modules는 임시 도구 경로를 가리키는 무시 대상 심볼릭 링크이며 .gitignore의 node_modules 항목은 링크도 제외하도록 끝에 슬래시를 붙이지 않는다.
CLI 계정 인증정보와 서비스 계정 키는 공개 저장소에 추가하지 않는다.

## 환율·앱 연결과 한계

Frankfurter 최신 영업일 USD/JPY 참고 환율과 제공 날짜를 표시한다.
50달러 이상이 되는 최소 정수 엔 금액은 ceil(USD/JPY × 50)이며 실제 카드사 환산과 차이가 있을 수 있다.
조회 실패 시 같은 페이지 메모리에 남아 있는 24시간 이내 환율 또는 직접 입력을 사용하며 환율 없이 달러 조건을 임의 판정하지 않는다.
느린 자동 조회가 직접 입력값을 덮어쓰지 않도록 처리한다.
직접 입력한 환율은 같은 페이지의 메모리에서 24시간 동안 유효하며 재접속 시 새로 조회한다.
브라우저에 로그인 정보만 남기도록 기존 환율 localStorage 캐시는 제거했다.
페이지 시작 시 자동 조회하며 다른 화면에서 돌아오면 마지막 자동 환율 조회가 30분 이상 지났을 때 갱신한다.
페이지를 계속 보고 있는 동안 주기적으로 조회하는 타이머는 없다.

사용자는 카카오페이 머니·일본·알리페이 직접 연결 링크도 조사하도록 지시했다.
공식 해외결제 사용법 https://story.kakaopay.com/338-kakaopay-global/ 에서 카카오페이 앱 → 결제하기 → 국가 선택, 페이머니 사용, Alipay+ 가맹점 결제를 확인했다.
공식 link.kakaopay.com의 연결 페이지 코드에서 /p/<경로>가 kakaopay://<경로>로 연결됨을 확인했다.
카카오페이 추천 예상 시 사용자 탭에서 창을 준비하고 Firestore 저장이 확정되면 https://link.kakaopay.com/p/payment 로 연결한다.
서버의 최종 추천이 다른 결제수단이면 준비한 창을 닫으며 카카오페이 재시도 링크도 제공한다.
일본 국가나 Alipay+를 강제 지정하는 공개 파라미터는 확인하지 못해 앱 안에서 일본·페이머니·Alipay+를 확인하도록 안내한다.
실제 휴대전화 앱 화면 이동까지 검증한 것으로 확대하지 않는다.
초기 후보인 kakaotalk://kakaopay/payment/offline 대신 카카오페이 앱 링크를 사용한다.
